# Proyecto Shell-Script SSH

Práctica de ASIR para la automatización del servicio SSH usando Bash, Ansible, Docker y GitHub.


- `gestion_ssh.sh`: script principal con menú y modo por parámetros.
- `ssh_install.yml`: playbook de Ansible para instalar SSH.
- `Dockerfile`: imagen Ubuntu con SSH.
- `capturas/`: evidencias de ejecución.
